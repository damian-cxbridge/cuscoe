# Changelog

## Version 1.0 (2026)

First public release. Covers the eleven design principles, the two rules and the three-layer pricing model, consistent with the framework presented at KMIS 2026.

Changes from the pre-publication model, made during the research for the KMIS paper:

- added the three-layer pricing model for services where AI carries variable cost
- defined what each function contributes to the Portfolio and how conflicts are resolved
- changed finance from approving each proposal to approving the cost model once and signing off outliers
- added an escalation route between IT, compliance, legal and the Centres of Excellence in place of a veto
