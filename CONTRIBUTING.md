# Contributing

Feedback on CUSCOE is welcome. The most useful contributions are reports from organisations that have applied part of the model, gaps you have found, and places where the text is unclear.

## How to contribute

Open an Issue describing the problem or suggestion. Issues are the preferred route for all feedback.

Pull requests that change the text of the model can only be accepted if the contributor agrees in writing to assign their rights in the contribution to CX Bridge Ltd. This keeps ownership of the model in one place so it can continue to be licensed consistently. Contributors are credited in the changelog.

## Adapted versions

If you want to publish your own adapted version rather than contribute to this one, you can do so under the licence. Please follow the [trademark policy](docs/trademark.md) on naming.
